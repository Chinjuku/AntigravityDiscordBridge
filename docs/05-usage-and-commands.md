# 📖 05 - คู่มือคำสั่งและการใช้งาน (Usage & Commands)

เอกสารรวบรวมคำสั่งทั้งหมดสำหรับใช้งานผ่านแชท **Discord**, คำสั่ง **CLI** (`ask-agent`, `report-agent`) และ **HTTP API Endpoints**

---

## 📱 ส่วนที่ 1: คำสั่งควบคุมผ่านแชท Discord (จากมือถือ/พีซี)

คุณสามารถควบคุม AI ได้ทั้งผ่าน **Slash Commands (`/`)** ที่มีระบบ Auto-complete, **Dropdown Menu & Pop-up Modal**, หรือ **Text Commands (`!`)** ในห้อง Discord ที่ตั้งค่าไว้ได้ทันที:

### 1. คำสั่ง Slash Commands (แนะนำ — มี Auto-complete ชื่อโปรเจกต์)
เพียงพิมพ์เครื่องหมาย `/` ในช่องแชท Discord ระบบจะแสดงเมนูคำสั่งพร้อมช่วยค้นหาชื่อโปรเจกต์ให้อัตโนมัติ:

| Slash Command | คำอธิบาย |
| :--- | :--- |
| `/ai project:<ชื่อโปรเจกต์> prompt:<คำสั่ง>` | สั่งงาน AI ไปยังโปรเจกต์ที่เลือก (ช่อง `project` รองรับการพิมพ์ค้นหาแบบ **Auto-complete** จากโปรเจกต์ทั้งหมดในเครื่อง) |
| `/projects` | แสดงรายการโฟลเดอร์โปรเจกต์ทั้งหมดที่สแกนเจอ พร้อม **Dropdown Select Menu** ให้คลิกเลือกโปรเจกต์ |
| `/status` | ตรวจสอบสถานะงานที่กำลังรันอยู่, เวลาที่ใช้ไป, คิวงานที่รอ และคำถามที่รอคำตอบ |
| `/stop [project:<ชื่อโปรเจกต์>]` | ยกเลิก/หยุดโปรเซส `agy` ของโปรเจกต์ที่กำลังรันอยู่ทันที (มี Auto-complete) |
| `/help` | แสดงคู่มือการใช้งานย่อในห้องแชท Discord |

---

### 2. การเลือกโปรเจกต์ผ่าน Dropdown Menu และสั่งงานด้วย Pop-up Modal
1. พิมพ์ `/projects` (หรือ `!projects`) บอทจะแสดงการ์ดรายชื่อโปรเจกต์พร้อม **Dropdown Menu**
2. คลิกเลือกโฟลเดอร์โปรเจกต์ที่ต้องการจาก Dropdown
3. บอทจะแสดงปุ่ม **"🚀 สั่งงาน AI ในโปรเจกต์นี้"** และ **"📊 ตรวจสอบสถานะ"**
4. เมื่อกดปุ่ม **"🚀 สั่งงาน AI ในโปรเจกต์นี้"** จะมีหน้าต่าง **Pop-up Modal** เด้งขึ้นมาให้พิมพ์คำสั่งยาวๆ ได้สะดวกโดยไม่ต้องพิมพ์โค้ดคำสั่งเอง

---

### 3. สั่งงาน AI ด้วยข้อความธรรมดา (`!ai` / `!do` / กด Reply)
| รูปแบบคำสั่ง | คำอธิบาย | ตัวอย่าง |
| :--- | :--- | :--- |
| **กด Reply ข้อความบอท** | กด **Reply (ตอบกลับ)** ที่การ์ดรายงานผลของบอท แล้วพิมพ์คำสั่งต่อยอดในโปรเจกต์นั้นได้ทันที (ไม่ต้องพิมพ์ `/ai` หรือ `!ai`) | *(Reply)* `ช่วยรันเทสต์และแก้ให้ผ่านด้วย` |
| `!ai <คำสั่ง>` หรือ `!do <คำสั่ง>` | สั่งงานให้ AI รันในโปรเจกต์ล่าสุดที่เพิ่งใช้งาน | `!ai แก้บั๊กหน้า Login ให้หน่อย` |
| `!ai [ชื่อโปรเจกต์] <คำสั่ง>` | สั่งงานเจาะจงโปรเจกต์ที่ต้องการ (รองรับการค้นหาชื่อแบบ Case-insensitive และ Substring) | `!ai [my-web] เพิ่มปุ่ม Dark Mode` |

---

### 4. การตอบคำถามและตัดสินใจ (`/ask`)
เมื่อ AI ส่งการ์ดคำถามสีน้ำเงินมาในห้อง Discord:
- **กรณีมีปุ่มกด (Buttons)**: คลิกปุ่มตัวเลือกที่ต้องการได้เลย ปุ่มจะถูกล็อกอัตโนมัติเพื่อป้องกันการกดซ้ำ และอัปเดตสถานะว่าใครเป็นผู้กดเลือก
- **กรณีถามแบบข้อความ (Text)**:
  - กด **Reply** ที่ข้อความคำถามแล้วพิมพ์คำตอบ
  - หรือพิมพ์ข้อความตอบลงในห้องแชทโดยตรง (หากไม่ขึ้นต้นด้วย `!` หรือ `/` ระบบจะส่งเป็นคำตอบให้คำถามล่าสุดทันที)

---

### 5. คำสั่ง Text Commands เพิ่มเติม (จัดการโปรเจกต์ คิวงาน และการยกเลิก)
| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| `!help` | แสดงคู่มือคำสั่งทั้งหมดใน Discord |
| `!status` หรือ `!queue` | ดูรายการงานที่กำลังรันอยู่, คิวงานที่รอ และคำถามที่ค้างอยู่ |
| `!projects` หรือ `!list` | สแกนและแสดงรายชื่อโปรเจกต์ทั้งหมดพร้อม Dropdown Menu ให้กดเลือก |
| `!prompt [ชื่อโปรเจกต์] <คำสั่ง>` | เพิ่มคำสั่งเก็บเข้าคิวงานไว้ล่วงหน้า |
| `!stop` หรือ `!cancel [ชื่อโปรเจกต์]` | ยกเลิก/หยุดโปรเซส `agy` ที่กำลังรันอยู่ทันที |

---

## 💻 ส่วนที่ 2: การใช้งาน CLI (`ask-agent` และ `report-agent`)

สคริปต์ทั้งสองจะตรวจจับชื่อโปรเจกต์จากชื่อโฟลเดอร์ Git ปัจจุบันให้อัตโนมัติ (หรือกำหนดผ่านตัวแปร `DISCORD_PROJECT` ได้)

### 1. คำสั่ง `ask-agent`
ใช้สำหรับส่งคำถามไปที่ Discord และหยุดรอจนกว่าผู้ใช้จะตอบกลับมา (Timeout เริ่มต้น 600 วินาที / 10 นาที)

**รูปแบบ:**
```bash
ask-agent "<คำถาม>" "[type: text|buttons]" "[options]" "[project]"
```

**ตัวอย่างการใช้งาน:**
```bash
# 1. ถามแบบมีปุ่มตัวเลือก (รูปแบบตัวเลือก: id:ข้อความบนปุ่ม:สีปุ่ม)
# สีปุ่มที่รองรับ: Primary (น้ำเงิน), Secondary (เทา), Success (เขียว), Danger (แดง)
USER_REPLY=$(ask-agent "ต้องการ Deploy ขึ้น Production เลยไหม?" "buttons" "deploy:Deploy เลย:Success,cancel:ยกเลิกก่อน:Danger")
echo "ผู้ใช้เลือก: $USER_REPLY"

# 2. ถามแบบพิมพ์ตอบอิสระ
USER_REPLY=$(ask-agent "ต้องการตั้งชื่อตารางฐานข้อมูลว่าอะไร?" "text")
echo "ผู้ใช้ตอบว่า: $USER_REPLY"
```

---

### 2. คำสั่ง `report-agent`
ใช้สำหรับส่งการ์ดรายงานสถานะเข้า Discord แบบไม่บล็อกการทำงาน (Non-blocking)

**รูปแบบ:**
```bash
report-agent [status] "<ข้อความสรุป>" "[รายชื่อไฟล์]" "[โค้ดตัวอย่าง]"
```
*(สถานะ `status` ที่รองรับ: `started`, `progress`, `completed`, `failed`)*

**ตัวอย่างการใช้งาน:**
```bash
# รายงานเมื่อเริ่มงาน
report-agent started "กำลังเริ่ม Refactor ระบบตะกร้าสินค้า"

# รายงานความคืบหน้า
report-agent progress "อัปเดต API เส้นชำระเงินเสร็จแล้ว กำลังเขียน Unit Test"

# รายงานเมื่อเสร็จสมบูรณ์ พร้อมแนบชื่อไฟล์และโค้ด
report-agent completed "เพิ่มระบบคูปองส่วนลดเสร็จสมบูรณ์" "src/cart.ts, src/coupon.ts" "export const applyCoupon = (code: string) => { ... }"

# รายงานเมื่อเกิดข้อผิดพลาด
report-agent failed "Build ไม่ผ่านเนื่องจาก Type Error ในไฟล์หน้า Checkout"
```

## 🌐 ส่วนที่ 3: HTTP API Endpoints (`localhost:4321`)

หากต้องการเชื่อมต่อจากโปรแกรมหรือภาษาอื่นโดยตรง สามารถยิง HTTP Request มาที่ `http://localhost:4321` ได้ดังนี้:

| Method | Endpoint | คำอธิบาย |
| :--- | :--- | :--- |
| `POST` | `/ask` | ส่งคำถามเข้า Discord และรอรับ JSON `{ "response": "..." }` กลับ |
| `POST` | `/report` | ส่งการ์ดรายงานสถานะ (`started`, `progress`, `completed`, `failed`) |
| `GET` | `/get-next-prompt?project=<name>` | ดึงคำสั่งถัดไปจากคิวของโปรเจกต์ที่ระบุ |
| `GET` | `/projects` | ดูรายชื่อโปรเจกต์และ Path ทั้งหมดใน `projects.json` |
| `GET` | `/status` | ดูสถานะงานที่กำลังรัน, จำนวนคำถามที่รอ และคิวงานทั้งหมด |
